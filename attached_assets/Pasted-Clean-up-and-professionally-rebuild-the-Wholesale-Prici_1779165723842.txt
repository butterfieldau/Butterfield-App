Tier: Premium Wholesale
Qty 12+ = $4.20 each
Qty 24+ = $3.90 each
Qty 48+ = $3.50 each

Only Director and Master accounts should be able to control this.

Pricing priority logic:
The app must follow this exact order:

1. Custom Pricing Per Customer
If a customer has a custom price for a product, use that price first.

2. Quantity Breaks
If there is no custom customer price, check if there is a manually created qty break for that product and the customer’s assigned tier.

3. Tier Pricing
If there is no custom price and no qty break, use the assigned tier price if one exists.

4. Default Wholesale Price
If no custom pricing, qty break or tier price exists, use the default wholesale product price.

5. Do not apply anything
If no wholesale price has been created, do not guess or create a discount automatically.
